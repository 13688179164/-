# GOODWORK 古德車房 · 悬浮生态财务工作台

一个悬浮在深空中的透明玻璃立方体微缩世界。岛上有雪山、蜿蜒河流、悬空瀑布、湖泊、森林、草地、微型动物与漂浮云朵，中心是双层玻璃幕墙的 **GOODWORK 古德車房**。

点击车房会触发三段缓动运镜、场景虚化与右侧滑入的报销表单，形成从「三维世界」到「财务工作流」的完整闭环。

> 注：当前运行环境是 Linux 工作区，项目位于 `/workspace/goodwork-garage`。如需按原计划放在 D 盘，只需将整个 `goodwork-garage` 文件夹复制到 `D:\goodwork-garage`，运行方式完全一致。

## 1. 快速开始

### 方式 A：Node.js 静态服务器（推荐）

要求 Node.js 18+，无需安装任何依赖。

```bash
cd goodwork-garage
npm start
```

打开 `http://localhost:5173`。

也可以直接运行：

```bash
node server.mjs
# 指定端口
PORT=8080 node server.mjs
```

### 方式 B：Python 静态服务器

```bash
cd goodwork-garage
python3 -m http.server 8080
```

打开 `http://localhost:8080`。

> 必须通过 HTTP 服务访问，不能直接双击 `index.html`。项目使用原生 ES Modules + importmap，`file://` 协议会因模块路径限制而无法加载。

### 浏览器建议

- Chrome / Edge / Safari 最新版，需支持 WebGL2。
- 首次点击/按键后才会启用 WebAudio 氛围声（浏览器自动播放策略限制）。
- 推荐独立显卡或较新的集成显卡；移动端会自动降低粒子数量与像素比。

## 2. 操作说明

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 旋转悬浮世界 |
| 滚轮 / 双指 | 推近 / 拉远 |
| 点击车房 | 三段运镜推进 + 场景虚化 + 报销表单滑入 |
| 点击其他设施 | 右侧档案面板；票据箱可派发 NPC 取票 |
| 点击季节按钮 | 春 / 夏 / 秋 / 冬平滑切换，并重置自动切换计时 |
| Esc | 关闭面板 / 表单并恢复镜头 |
| 右上角声音按钮 | 开启 / 静音合成氛围声 |

### 报销工作流

1. **取票**：点击广场上的票据箱，或在发票单中点击「一键同步票据」。员工林晓会沿 A* 路径前往票据箱并归集 3 张票据。
2. **提交**：进入 GOODWORK 车房，填写申请人、部门、费用类型、事由、金额，勾选票据后提交。票据箱同步的票据可勾选/取消。
3. **审批**：提交后自动进入审批流，约 6.8 秒后自动通过；也可以关闭面板，点击广场上的审批终端立即审批。通过后写入右侧档案库，任务链闭环。

任务链卡片（左下）始终显示当前状态，可点击对应的进行中步骤进行追踪。

## 3. 功能实现清单

### 3.1 场景

- 悬浮岛：程序化地形高度场、岩层断崖、悬挂根系、岛底漂浮碎岩与冷光晕。
- 雪山：程序化多峰高度场，顶点色融合岩石 / 积雪，含山脊噪声与雪线。
- 水体：蜿蜒河道、圆湖、石质溢流槽、双层动态瀑布、木栈桥、小木船、睡莲。
- 植被：35 棵树（阔叶 / 松树 / 樱树）、约 200 组灌木、草簇、花丛、蘑菇、苔石。
- 动物：两只微缩鹿、三只环湖飞鸟、蝴蝶。
- 大气：6 组黏土云、16 组薄雾、深空星野、远景行星、散景光斑。

### 3.2 车房建筑

- 两层玻璃幕墙、黄铜竖挺、深色石材基座、门厅雨棚与入口门廊。
- **屋顶金边主招牌**、**左侧竖式灯箱**、**右侧双面侧招**、入口门牌与品牌门饰。
- 一层展厅：双柱举升机、深酒红 GT 跑车、接待台、财务 OS 屏幕、工具柜、轮胎、绿植与技师。
- 二层财务工作区、暖光灯带、品牌背光墙与楼上设备间。
- 配套建筑：财务室、仓库、员工宿舍，以及配送车、停车牌、庭院路灯、票据箱、审批终端。

### 3.3 四季系统

默认每 **18–28 秒**随机切换，也可手动点选。过渡时长约 2–3 秒。

| 季节 | 天气粒子 | 环境变化 |
| --- | --- | --- |
| 春 | 樱瓣 1,100 | 暖光、嫩绿、樱花 |
| 夏 | 雨丝 1,200（LineSegments 单批次） | 高亮冷光、深绿、雨噪氛围声 |
| 秋 | 橙叶 1,050 | 琥珀光、橙叶、薄雾 |
| 冬 | 细雪 1,300 | 冷蓝光、地面积雪、屋顶/树冠覆雪、湖岸冷色 |

- 天气系统常驻内存，切换时只插值 `uOpacity`；一个季节只有 1 个天气 draw call。
- 独立环境浮尘 280 粒（加色混合、缓升闪烁），与季节特效并行。
- 焊接火花 140 粒（移动端 84），使用独立的 Points 更新位置与颜色。

### 3.4 22 类可交互元素

主建筑、主招牌、竖式灯箱、侧招、举升机车辆、票据箱、审批终端、停车牌、路灯、配送车、环道车流、环岛樱树、镜湖、悬空瀑布、雪峰、微缩鹿群、财务室、仓库、员工宿舍、NPC、漂浮云朵、薄雾。

- 悬停：鼠标指针变化、金色光环、世界空间标签高亮、跟随鼠标提示浮层、WebAudio 轻音。
- 点击：右侧档案面板展示分类、参数、实时档案与标签；部分入口提供「进入车房 / 取票 / 审批 / 派发任务」等操作。
- 拾取防遮挡：玻璃标记 `userData.glass`，射线优先返回非玻璃命中，因此在玻璃外可以直接点击内部举升机跑车；玻璃本身仍可点击进入车房。

### 3.5 NPC 系统

- 4 名员工：林晓（财务）、陈默（仓储）、苏禾（接待）、周野（技术服务）。
- **32 × 22 导航网格**，8 向 A*，禁止斜穿墙角。
- 视线路径平滑（string pulling），到达目标或遇障时重新规划。
- 同伴分离力、卡住检测与重规划。
- 步行腿部 / 手臂反相摆动、头部环视、朝向最短角插值、抵达后自动转入 idle/巡逻。
- 任务链：林晓取票送到车房、提交后前往审批终端，审批后回到车房。

### 3.6 车流与行人

- 8 台环道车辆使用 `InstancedMesh`：车身（实例色）、座舱玻璃、四轮、前灯、尾灯，共 5 个绘制批次并逐帧更新实例矩阵。
- 20 名行人使用 2 个 `InstancedMesh`（身体 + 头部），沿三条步道循环并带轻微上下浮动。
- 金色路缘、合并为单批次的环道虚线、程序化石材广场、铜章与引导牌。

### 3.7 镜头与业务衔接

- 点击车房：相机沿三个关键帧推进（0.95s / 0.95s / 1.05s，`easeInOutCubic/Quint`），场景在约 0.46s 后开始 CSS 景深虚化；表单在约 1.65s 从右侧滑入。
- 关闭表单 / Esc：镜头缓动回到进入前位置，虚化与光晕同步恢复。
- 虚化期间保留任务链与底部提示，业务操作与 3D 渲染互不阻塞。

## 4. 技术结构与性能

### 目录

```text
goodwork-garage/
├── index.html               # 页面骨架 + importmap + UI 结构
├── styles.css               # 深空 / 黄铜 UI、面板、表单、响应式
├── server.mjs               # 零依赖静态服务器（npm start）
├── src/
│   ├── main.js              # 渲染器、Composer、灯光、装配、运镜、主循环
│   ├── audio.js             # WebAudio 氛围声与交互音效
│   ├── core/
│   │   ├── config.js        # 季节调色板、相机、员工、票据、参数
│   │   ├── archive.js       # 22 类交互档案文案
│   │   ├── textures.js      # 全部程序化 CanvasTexture
│   │   └── utils.js         # 噪声、随机、缓动、补间、投影
│   ├── world/
│   │   ├── terrain.js       # 地形高度、河流/湖泊、用地与障碍数据
│   │   ├── island.js        # 地形网格、断崖、雪山、水、植被、动物
│   │   ├── buildings.js     # 车房 + 财务室 + 仓库 + 宿舍
│   │   ├── props.js         # 广场、环道、车流、行人、票据箱、终端、路灯
│   │   ├── environment.js   # 深空、玻璃立方体、云、雾、行星
│   │   └── materials.js     # 玻璃/水体/瀑布着色器与材质库
│   ├── systems/
│   │   ├── particles.js     # 四季天气、浮尘、焊接火花
│   │   ├── seasons.js       # 季节状态与平滑过渡
│   │   ├── npc.js           # A* 导航与 NPC 动画
│   │   ├── interaction.js   # 拾取、光环、标签、浮层
│   │   └── quest.js         # 报销业务与 NPC 任务链
│   └── ui/ui.js             # 面板、表单、任务链、档案库、Toast
└── vendor/three/            # Three.js r164 及必要 addons（本地化，无 CDN）
```

### 渲染与性能

- Three.js `r164` 本地 vendor，原生 ESM + importmap，无构建步骤、无 CDN 依赖。
- `EffectComposer`：RenderPass + UnrealBloomPass + OutputPass（ACES Filmic）。
- 像素比上限 1.75；移动端降低体力消耗更大的粒子数量。
- **1 盏平行光投影**，阴影贴图 1024²；首帧后冻结静态阴影贴图（NPC / 行人 / 车流默认不投影），显著降低逐帧阴影 draw call。
- 只在必要处开启透明材质和逐帧实例矩阵更新。
- 在地道路标线、幕墙竖挺、品牌灯带等处尽量合并几何；天气每种只有 1 个 Points / LineSegments。
- 桌面测试环境（Chrome + SwiftShader 软件渲染）约 690 个绘制批次、约 10.7 万三角形、1,520 个粒子；真实硬件 GPU 下帧率更高。
- 所有纹理（深空、招牌、草地、石材、水纹、行星、雾、铜章等）均在运行时程序化生成，不依赖外部图片。

### 调试入口

开发时可在控制台使用：

```js
window.__GOODWORK__.app           // 应用实例
window.__GOODWORK__.seasonInstant('winter')   // 立即切换季节（跳过过渡）
window.__GOODWORK__.focusInstant()            // 立即进入车房表单状态
window.__GOODWORK__.season.id
window.__GOODWORK__.ui.records
```

URL 参数：

- `?season=winter`：以冬季初始化（无过渡）。
- `?nointro=1`：跳过开场镜头。
- `?test=1`：测试模式（跳过开场，方便自动化截图）。

示例：`http://localhost:5173/?season=autumn&test=1`

## 5. 开发说明

### 修改季节

编辑 `src/core/config.js` 的 `SEASONS` 数组：雾色、雾密度、半球光、主光、轮廓光、环境光、曝光、Bloom、植被色、水体色、玻璃色、积雪强度等。`src/systems/seasons.js` 会自动插值并驱动材质。

### 修改招牌 / 文案

- 招牌文字与排版：`src/core/textures.js` 中 `makeMainSignTexture` / `makeVerticalSignTexture` / `makeBladeSignTexture`。
- 建筑铭牌：`makeBuildingSignTexture`。
- 档案面板文案：`src/core/archive.js`。
- 表单字段 / 票据数据：`src/core/config.js` 的 `EMPLOYEES` / `RECEIPTS` / `EXPENSE_TYPES`。

### 增加可交互元素

1. 在对象 mesh 上设置 `userData.interactiveKey = 'yourKey'`（玻璃请加 `userData.glass = true`）。
2. 在 `src/core/archive.js` 增加档案文案。
3. 在 `src/systems/interaction.js` 的 `config` 中增加锚点、光环半径和标签开关。
4. 如需要点击动作，在 `src/ui/ui.js` 的动作里增加分支，并在 `src/main.js` 的 `handleAction` 中处理。

### NPC 寻路

- 导航数据由 `src/world/terrain.js` 的水域、建筑矩形与 `src/world/island.js` 的树干障碍共同生成。
- `NPCSystem` 在 NPC 达到目标或卡住时重新计算 A*，并做视线平滑；不需要每帧计算网格。
- 新增 NPC 时扩展 `EMPLOYEES` 并在 `NPCSystem` 中自动创建。

### 粒子

- `src/systems/particles.js` 中每种天气是常驻的单个 Mesh，季节切换仅改 `uOpacity`。
- 增加天气类型时沿用 `WeatherPoints` / `RainSystem` 的结构，避免创建/销毁几何体。

## 6. 已知说明

- 报销记录保存在当前页面的内存中，刷新页面会重置为演示档案（含 1 条历史归档记录），不连接真实后端。
- 审批为本地模拟流程：提交后 6.8 秒自动通过，也可点击审批终端立即通过。
- 中文排版依赖系统中文字体（Noto Sans/Serif CJK、苹方、微软雅黑等）；无中文字体时浏览器会回退到默认字体。
- 声音需要用户首次交互后才能播放；不交互时保持静音是浏览器策略。
- 本项目为前端演示，不包含真实账号、票据 OCR、数据库或审批服务。
