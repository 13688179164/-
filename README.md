# GOODWORK 古德車房 · 三维财务报销工作台

以「夜班汽修店」为舞台的三维财务报销中控台。双层玻璃车房、金边招牌、湿柏油反光与深空城市背景全部在浏览器中实时生成；22 个可交互资产、四季天气粒子、A* NPC 与报销表单共同组成一个可演示的业务闭环。

- 技术栈：Three.js 0.171 + Vite 5
- 无需任何外部模型、贴图或音频文件：几何、招牌、路面、屏幕、雪层与音效均为运行时程序化生成
- 桌面端建议开启硬件加速；浏览器需要支持 WebGL 2

---

```bash
npm install
npm run dev
# 打开 http://localhost:5173
```

生产构建与本地预览：

```bash
# 打开 http://localhost:4173
```

构建产物在 `dist/`，使用相对路径，可直接放到任意静态服务器子目录。

## 交互指南

### 场景

- **拖动**：绕主楼旋转视角（限定在正面弧内，避免露出未建面）
- **滚轮 / 双指**：缩放
- **悬停资产**：金色光环、跟随鼠标的提示浮层、世界空间标签、悬停音效
- **点击资产**：打开右侧档案面板，查看参数、关联单据与建议报销额度
- **点击 GOODWORK 主楼**：三段 cubic-in-out 镜头推进 → 场景虚化 → 报销表单从右侧滑入
- **点击财务室 / 仓库 / 宿舍**：打开该建筑的档案，在档案中「发起报销」同样会触发镜头推进与表单

### 顶部与 HUD

- **四季按钮**：手动切换春 / 夏 / 秋 / 冬；光照、雾、天空、玻璃、植被、积雪与粒子同步过渡
- **自动轮转**：默认每 18–28 秒随机切换；倒计时显示在按钮内
- **电影运镜**：缓慢环绕与自动回位；拖动后暂停，空闲 6.5 秒后恢复
- **音效**：悬停、点击、提交、季节切换等 WebAudio 合成音效；首次点击后解锁 AudioContext
- **场景标签**：显示 / 隐藏票据箱、审批终端与 NPC 的世界空间标签
- **复位视角**：1.25 秒缓动回到主构图
- **发起报销**：直接进入主楼的报销流程

### 报销表单

1. 场景设施自动带入报销主体、科目、金额、供应商、成本中心与事项说明
2. 可修改类别、金额、日期、发票号、收款方与说明
3. 「添加发票附件」会模拟 OCR 验真并追加附件 chip
4. 选择支付方式，查看三级审批链
5. 「提交审批」：校验金额 → 成功态 → KPI 累计 → NPC 任务链重启（取票 → 提交 → 审批）
6. 关闭表单后镜头自动回到进入前的机位

### NPC 与任务链

4 名员工拥有各自的日常动线：

| NPC | 角色 | 动线 |
| --- | --- | --- |
| 林晓 | 报销专员 | 票据箱取票 → 审批终端提交 → 财务室审批 |
| 郑野 | 机修主管 | 举升机 → 仓储中心 → 工作台巡检 |
| 苏禾 | 财务复核 | 财务室 ↔ 审批终端，审批节点协同时前往财务室 |
| 阿凯 | 仓储配送 | 仓储中心 → 配送车 → 员工宿舍 |

底部任务链 HUD 会实时点亮取票 / 提交 / 审批节点，并显示当前单据号。NPC 到达节点、完成审批时都会反馈音效与提示。

## 六项需求的实现位置

1. **核心建筑与过渡**
   - 主楼：双层玻璃幕墙、金色竖框、金边主招牌、竖式灯箱、双面侧招、屋顶灯箱、入口雨棚与暖色内景
   - 点击主楼由 `main.js` 执行三段缓动镜头（`cameraStages`），完成后 `body.form-open` 触发 `.scene-layer` 的 CSS 虚化 + `transform` 表单滑入
2. **四季环境**
   - `src/scene/season.js` 内四套常驻粒子系统与季节参数；颜色、雾、光照、玻璃、植被、积雪、路面湿度全部逐帧阻尼过渡
   - 春 1100 樱瓣 / 夏 900 雨丝 / 秋 1000 落叶 / 冬 1300 细雪；冬季同步屋顶、树冠、车顶、招牌与雨棚积雪
3. **全场景交互**
   - `world.js` 注册 22 个 entry，统一金色 billboard 光环、鼠标跟随提示、WebAudio 音效与右侧档案面板
   - 玻璃幕墙标记 `userData.glass`；射线优先返回玻璃后的举升机、工作台、轮胎架、前台等非玻璃命中
4. **NPC**
   - `src/scene/npc.js`：32 × 22 网格 A*、8 向邻居、斜角防穿墙、视线路径平滑、动态障碍重规划、同伴分离、卡死恢复
   - 腿部 / 手臂摆动、躯干起伏、朝向最短角插值、世界空间姓名标签
5. **粒子**
   - 天气粒子每种一个 `Points` / `LineSegments` 绘制批次，自定义 ShaderMaterial 在 GPU 端绘制雪粒、花瓣、叶片与雨丝
   - 环境浮尘 280 粒（移动端 180）独立常驻；焊接火花 140 粒（移动端 84）独立 `Points`
   - 桌面全场景约 1,180–1,580 粒（不含短暂火花），移动端自动降级
6. **业务闭环**
   - 场景设施 → 档案面板 → 报销表单 → KPI 更新 → NPC 任务链 → 审批成功态；整条业务流全部在场景语境中完成

额外实现：财务室、仓储中心、员工宿舍三栋业务建筑；配送车与 NPC 任务链；GPU InstancedMesh 车流（12 辆）与行人（14 名）；Bloom 后处理。

## 技术设计

### 渲染与美术

- `WebGLRenderer` + `ACESFilmicToneMapping`
- `EffectComposer`：RenderPass → UnrealBloomPass（阈值 0.66）→ OutputPass
- 半浮点渲染目标；桌面 2× MSAA；像素比上限 1.75（移动端 1.5）
- 唯一投影光源为主平行光，1024² 阴影图；其它点光不投影
- 天空为自定义 ShaderMaterial 渐变 + 星点 + 月亮光晕 + 星云 + 两层城市剪影 + 山脊 + 城市地平线辉光
- 湿路面使用 MeshPhysicalMaterial（clearcoat）+ 程序化沥青 CanvasTexture + 附加湿地面 sheen + 长短不一的灯光反射带
- 所有招牌、屏幕、票据箱面板、道路标线、积雪 alpha 均由 CanvasTexture 绘制

### 绘制批次优化

- 建筑外壳按“材质 + 投影/接收阴影 + 几何属性”合批
- 灯杆、树木、车辆、票箱、终端、配送车等交互资产内部合批
- 非交互静态装饰在世界空间再次按材质合并
- 交互节点仍保留独立包围体与拾取语义；合批后典型 1440 × 900 QA 场景约 330 个 draw call（初版约 585）
- 车流与行人使用 InstancedMesh；车灯使用一个附加 Points 批次

### 粒子策略

- 四套季节天气系统启动时一次性创建，运行时只切换 `uOpacity`，归零后隐藏，不重建几何
- 每帧 CPU 只更新位置数组，形状与旋转在片元 / 顶点着色器内完成
- 环境浮尘与季节系统独立，因此不会互相覆盖或抢占批次

### NPC 寻路

- 网格：32 × 22，`CELL_X = 2`、`CELL_Z = 1.35`，覆盖门前广场
- A*：八方向；斜向移动前检查两侧正交格；世界距离作为 g 值；欧氏启发
- 路径平滑：逐段视线检测，拉直可直达的 waypoint
- 动态重规划：同伴占位作为临时障碍；卡死计时触发重算；异常进入阻塞格时恢复到最近可用格
- 同伴分离：1.15 m 半径内叠加排斥力，避免重叠

### 状态与过渡

- 四季：`season.state` 逐帧阻尼插值到目标；颜色用 `THREE.Color.lerp`，标量用指数平滑
- 镜头：`tweenCamera` 以 cubic-in-out 插值相机位置与 target；表单流程期间锁定 OrbitControls
- 表单：CSS `transform` + `.scene-layer` 的 `filter: blur(...)`；表单滑入与镜头第三段并行，不阻塞渲染循环

### 交互拾取

- 只对注册的 `world.pickables` 做 raycast，避免装饰物干扰
- 若最近命中为玻璃，则继续寻找被标记为内部优先级的非玻璃资产（举升机 / 工作台 / 轮胎 / 前台）；否则点击归属于主楼
- 拖拽超过 6 px 或超过 750 ms 不会触发点击

## 视觉 QA 模式（开发辅助）

在地址后加 `?qa=1`：

```
http://localhost:5173/?qa=1
```

该模式关闭 Bloom / 阴影 / MSAA，并将渲染改为手动步进，便于在软件渲染或低配环境中做画面回归。控制台可访问：

```js
__GW_DEBUG.advance(6)                // 推进 6 秒模拟与镜头
__GW_DEBUG.renderNow()               // 渲染一帧
__GW_DEBUG.selectEntry('finance')    // 打开指定资产档案
__GW_DEBUG.focusGarage()             // 触发主楼报销流程
__GW_DEBUG.setSeasonNow('summer')    // 立即切季并推进
```

正式演示请使用默认地址，不要加 `?qa=1`。

## 说明与限制

- 这是前端演示工作台：报销提交、KPI、单据与 NPC 任务状态保存在内存中，刷新页面会重置；未连接真实 ERP / 审批后端
- 音效需要用户首次点击页面后才能播放（浏览器自动播放策略）
- 场景需要 WebGL 2；远程桌面、无 GPU 的虚拟机或关闭硬件加速的浏览器可能无法创建上下文
- 移动端已适配（自动隐藏左栏、季节按钮折叠、表单全屏、粒子降级），完整体验建议桌面端
